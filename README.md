# Финальный проект курса «Автоматизация тестирования на Python» (Спринт 7)

## Автоматизация API учебного сервиса «Яндекс Самокат»

В этом проекте реализованы автоматизированные тесты для бэкенда сервиса **Яндекс Самокат** (эндпоинты курьеров и заказов). Проект построен по модульному принципу, отделяет тестовые данные от логики проверок и генерирует наглядные визуальные отчеты.

### 🛠 Использованные технологии
* **Python 3** — базовый язык проекта.
* **pytest** — фреймворк для организации и запуска тестов.
* **requests** — библиотека для отправки HTTP-запросов к API Самоката.
* **Allure Report** — инструмент для построения интерактивных отчетов с графиками.

---

### 📂 Структура проекта
* `data.py` — централизованное хранилище базового URL и всех эндпоинтов API (`URLS`).
* `helpers.py` — утилиты для автоматической генерации уникальных строк и валидных данных для новых курьеров.
* `requirements.txt` — список необходимых библиотек проекта.
* `tests/` — изолированная папка со всеми тестовыми сценариями:
  * `__init__.py` — служебный маркер пакета для корректной работы импортов Python.
  * `conftest.py` — конфигурация pytest, содержащая фикстуру `clean_courier` для автоматического создания курьера перед тестом и его удаления из базы Самоката после окончания теста.
  * `test_create_courier.py` — автотесты для ручки создания курьера (`POST /api/v1/courier`).
  * `test_login_courier.py` — автотесты для ручки авторизации курьера (`POST /api/v1/courier/login`), учитывающие особенности работы бэкенда при пустых полях.
  * `test_create_order.py` — параметризованные автотесты для ручки создания заказа (`POST /api/v1/orders`) с проверкой разных конфигураций цветов самоката (`BLACK`, `GREY`, оба или без цвета).
  * `test_get_orders_list.py` — автотесты для ручки получения списка заказов (`GET /api/v1/orders`).

### 🚀 Инструкция по запуску

1. **Клонировать репозиторий и перейти в папку проекта:**
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd qa_scooter_project
   ```

2. **Установить зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустить все тесты в подробном режиме:**
   ```bash
   pytest -v
   ```

---

### 📊 Генерация отчетов Allure

1. **Запустить тесты со сбором логов для Allure:**
   ```bash
   pytest --alluredir=allure_results
   ```

2. **Сгенерировать отчет и открыть его в браузере:**
   ```bash
   allure serve allure_results
   ```
